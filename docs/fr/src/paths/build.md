# Je ne code pas, mais je veux que Claude construise quelque chose pour moi

Pour vous si vous avez une idée — un petit outil, une page, un rapport — et
voulez que Claude la réalise, en gardant la main sur ce qui est construit.
Trois pages, une demi-heure environ, puis votre premier essai.

1. [Compagnon en deux minutes](../introduction.md)
2. [Partir de rien](../guides/start-from-nothing.md) : ce qu'il vous faut,
   les deux commandes à taper une fois, et votre première demande.
   Ensuite, vous parlez seulement à Claude.
3. [Relire un plan](../guides/review-a-plan.md) : avant que Claude
   construise, vérifiez que son plan dit ce que vous voulez.
