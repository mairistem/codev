# Choisissez votre parcours

Inutile de tout lire. Choisissez le profil le plus proche du vôtre et lisez
ses pages dans l'ordre ; le reste de la documentation est là quand vous en
avez besoin.

## Je découvre les agents IA

Vous avez entendu parler de Claude, l'avez peut-être essayé, et voulez voir
à quoi ressemble le travail avec un agent, en toute sécurité.

1. [Compagnon en deux minutes](introduction.md) : ce qu'il fait, qui décide.
2. [Glossaire](glossary.md) : les mots que vous rencontrerez.
3. [Votre première modification](quickstart.md) : essayez sur une petite idée.

## Je ne code pas, je relis et valide des plans

Vous êtes product owner, manager ou expert métier. Claude rédige le plan,
vous vérifiez qu'il dit la bonne chose, puis vous le validez.

1. [Compagnon en deux minutes](introduction.md) : les étapes et votre rôle.
2. [Relire un plan](guides/review-a-plan.md) : quoi vérifier, fichier par
   fichier, et comment demander des corrections.
3. [Glossaire](glossary.md) : proposition, spécification, scénario et le reste.

Vous écrivez du code et voulez que Claude planifie avant de coder.

1. [Votre première modification](quickstart.md) : le cycle complet, une fois.
