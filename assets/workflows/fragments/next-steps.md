## Suggesting the next step

Whenever you tell the user what to do next — the step after this one, the
way out of a refusal, the fix for a problem you report — give first the
words to say to you, in plain language and in the language the user writes
in, then the command in parentheses as a shortcut: say “archive it”
(shortcut: `/compagnon-archive`). The quoted requests below are written in
English: say them in the user's language. In French, use French words:
« modification » (not change), « compétence » (not skill), « spécification »
(not spec), « déroulé » (not workflow) — say « réalise la modification »,
not « applique le change ». Never present a command as the
only way, and never drop the command a reply below names: it stays, as the
shortcut.
