Partir d'un ticket Jira

Votre équipe décrit déjà le travail dans Jira. Nommez le ticket dans votre demande : Claude part du ticket, et le plan dit d'où il vient.

Pas de Jira ? Passez à Relire un plan→

  1. Vous dites « Prépare un plan pour PROJ-123 ».
  2. Claude lit le ticket une fois, sans rien changer dans Jira.
  3. Vous obtenez un plan qui le cite sur sa première ligne.

Exemple

Sous le capot : le mettre en place

Compagnon a besoin du nom de l'outil de lecture de ticket de votre connecteur Jira, dans _compagnon/config.yaml ; compagnon init le remplit s'il trouve un serveur Jira ou Atlassian dans votre configuration de Claude Code.

Sous le capot : ce que Claude peut faire avec Jira

Une lecture du premier ticket nommé. Jamais de recherche, de commentaire ni de changement de statut.

Votre première modification
