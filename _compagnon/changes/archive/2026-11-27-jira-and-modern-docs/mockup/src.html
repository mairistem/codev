Getting started

Install Compagnon

No Rust toolchain needed. Both scripts verify the SHA-256 of the binary they download.

macOS and Linux
curl -sSL https://raw.githubusercontent.com/mairistem/compagnon/main/install.sh | sh
Windows (PowerShell)
iwr -useb https://raw.githubusercontent.com/mairistem/compagnon/main/install.ps1 | iex

Then, in your project: compagnon init · Follow the quickstart →

Everyday use

Start from a Jira ticket

Your team already describes the work in Jira. Name the ticket in your request and Claude starts the plan from it: no copy and paste, and the plan says where it comes from.

  1. You say: “Prepare a plan for PROJ-123”.
  2. Claude reads the ticket — its title, description, status and type — once, without changing anything in Jira.
  3. You get a plan that cites it on its first line, so a reviewer sees which ticket it answers.
@@JIRA_DIAGRAM@@
No Jira connection? Claude says so, writes the plan from your request alone, and still names the ticket as “content not retrieved”.

Set it up

Jira reaches Claude Code through an MCP server — a connector to another tool. Compagnon only needs the name of its ticket-reading tool, in the project configuration:

_compagnon/config.yaml
mcp:
  jira_tool: mcp__atlassian__getJiraIssue

compagnon init fills it in for you when it finds a Jira or Atlassian server in your Claude Code setup.

What Claude may do with Jira

  • One call, to the one configured tool, for the first ticket named.
  • Never a search, a comment or a status change.
  • Other tickets you name are listed under the citation, for you to look up.
